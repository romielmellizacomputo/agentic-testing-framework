# Claude Code entry point

Read and follow `AGENTS.md` and `protocol/safety-rules.md`.

- Work only inside this repository; the app repository (`APP_REPO`) is read-only.
- Plan with `node tools/plan-run.mjs ...`, drive the browser, record with `node tools/record.mjs ...`, finish with `node tools/report.mjs latest`.
- Never read or print passwords; sign in with `node tools/browser/login.mjs <role>`.
