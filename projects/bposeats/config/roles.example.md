# BPOSeats (bposeats.com) roles

| Role key | Who |
|---|---|
| `anonymous` | Not signed in |
| `employer` | Client/employer with bookings and campaigns |
| `applicant` | Job seeker |
| `employee` | Hired staff |
| `approver` | Standing internal approver (secrets only) |

Accounts are created fresh per run where the app allows it; no existing person's account is stored here.
